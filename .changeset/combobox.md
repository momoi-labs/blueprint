Combobox chooses one value from a long list by typing part of its name or
description. Options can carry a note, a description, and a group. The value
and the query can be controlled, the match rule can be replaced, and the
product owns loading. Text that names no option is never a value. Select now
points to Combobox for long or remote lists.
